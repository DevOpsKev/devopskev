## DevOps Engineer · Platform Engineer · AI-Native · Cloud-Native · Author

Budapest · Dublin · Remote

I embed with enterprise clients and make complex technology work in production. I build pipeline architecture, operate platforms, and run the programmes that scale delivery across the enterprise. I've been early to every paradigm shift. XP and TDD in the late nineties. Agile in the early 2000s. Cloud-native and IaC in the 2010s. DORA metrics when Accelerate was still new. AI-native engineering now — and I'm writing the book on it.
